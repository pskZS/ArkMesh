## 3. 应用描述

```
ArkMesh — 您的鸿蒙私有网络安全助手

ArkMesh 是一款专为 HarmonyOS NEXT 设计的开源 VPN 客户端，支持连接您自建的 Headscale 服务器，让您轻松构建跨设备的私有网络。

【核心功能】
• 自建服务器连接：支持连接任意 Headscale 服务器，数据不经过第三方
• WireGuard 加密隧道：军事级别的加密通信协议
• 智能 NAT 穿透：基于 STUN 协议自动发现公网端点，P2P 直连更高效
• Noise 协议控制面：与 Headscale 服务器之间的安全通信
• 节点管理：实时查看网络中所有设备的在线状态
• 预认证密钥：支持 Auth Key 快速注册新设备
• 后台运行：VPN 连接持久化，切换应用不断线

【适用场景】
• 远程办公：安全访问公司内网资源
• 多设备互联：手机、平板、电脑组成私有网络
• 隐私保护：所有流量通过自己的服务器，不依赖第三方服务
• 开发测试：搭建测试网络环境

【使用前准备】
• 需要一台可公网访问的 Headscale 服务器（版本 0.24.0+）
• 建议在服务器上配置 HTTPS 证书
• 在 Headscale 后台生成预认证密钥

【开源透明】
本项目完全开源，代码可在 GitHub 查阅。欢迎开发者社区审查、贡献和改进。

注意：本应用仅供学习和研究使用。生产环境使用请自行评估安全性。
```

## 5. 权限说明

提交审核时需逐项说明权限用途：

| 权限 | 用途说明 |
|:---|:---|
| `ohos.permission.INTERNET` | 与 Headscale 服务器建立 HTTPS 连接，建立 WireGuard VPN 隧道 |
| `ohos.permission.GET_NETWORK_INFO` | 检测当前网络类型（WiFi/移动数据），在网络切换时自动重连 |
| `ohos.permission.KEEP_BACKGROUND_RUNNING` | VPN 连接需要在应用退到后台后持续运行，确保网络不中断 |

需创建一个在线隐私政策页面（可用 GitHub Pages 托管），内容如下：

```
ArkMesh 隐私政策

更新日期：2026年9月20日

1. 数据收集
   - 本应用不收集、存储或传输任何个人身份信息
   - 您输入的 Headscale 服务器地址和配置信息仅存储在本地设备

2. 权限使用说明
   - INTERNET（网络访问）：用于与 Headscale 服务器通信及建立 VPN 隧道
   - GET_NETWORK_INFO（网络信息）：用于检测当前网络状态和切换
   - KEEP_BACKGROUND_RUNNING（后台运行）：用于维持 VPN 连接不中断

3. 数据传输
   - 所有 VPN 流量通过您自建的 Headscale 服务器，不经过本应用开发者的服务器
   - 控制面通信使用 Noise 协议加密

4. 本地存储
   - 服务器地址、设备名称等配置存储在应用沙箱中
   - 加密密钥存储在设备安全区域

5. 第三方服务
   - 本应用不使用任何第三方分析、广告或追踪 SDK
   - STUN 服务器用于 NAT 穿透（可配置）

6. 开源声明
   - 本应用完全开源，代码接受社区审查

7. 联系方式
```

## 9. 审核注意事项

### VPN 类应用特殊要求

- 需要说明 VPN 功能的必要性（已在应用描述中覆盖）
- 隐私政策必须明确说明数据流向
- 可能需要提供 ICP 备案或相关资质（如果面向中国大陆用户）

### 内容合规

- 应用描述中不能出现"翻墙"、"绕过审查"等字样
- 强调"自建服务器"、"私有网络"、"企业远程办公"等合规场景
- 已按此要求撰写应用描述

### 技术合规

- `module.json5` 中的权限声明与实际使用一致
- VPN Extension Ability 已正确声明（type: vpn）
- 签名必须使用发布证书

### 提交前测试

- 确保在真机上完整测试
- 确保在无网络、弱网等异常场景下不会崩溃
- VPN 连接断开后应能自动重连或给出明确提示
